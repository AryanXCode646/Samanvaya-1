Article 1 • Overview

What is Samanvaya (समान्वय)?

Samanvaya (Sanskrit for Harmonization, Coordination, or Synthesis) is an open-source, industry-grade planetary image registration and tie-point correspondence engine. It was developed specifically to solve Smart India Hackathon (SIH) Problem Statement 26166 proposed by the Indian Space Research Organisation (ISRO):

"Multi-modal, Sun angle and scale invariant image correspondence using Chandrayaan-2 optical images (OHRC, TMC and IIRS)."

The Core Problem It Solves

When satellites orbit the Moon, they capture optical photographs under drastically varying conditions:

  • Extreme Opposite Sun Shadows: Because the Moon has no atmosphere, there is no ambient sky-glow. Shadows cast by crater walls are pitch-black voids. A morning image (Sun from East) and an afternoon image (Sun from West) look completely inverted. Traditional tools assume light and dark regions stay roughly the same—on the Moon, they completely flip!
  • Massive Scale Differences: Chandrayaan-2 carries instruments with wildly different resolutions: OHRC sees 25 cm per pixel, TMC-2 sees 5 meters per pixel (a 20× resolution gap), and IIRS sees 80 meters per pixel (a 320× gap). Traditional feature detectors cannot bridge a 20× zoom difference.
The Solution in 1 Sentence

Samanvaya extracts illumination-invariant physical step edges (Phase Congruency), finds dense correspondences across scales using LoFTR Transformers, prevents feature clumping using 8x8 Grid ANMS, and refines matches to sub-pixel precision (< 0.40 px) using analytical 2D parabolic Taylor series.

Article 2 • Technical Rationale

Why Did We Build This? (Why Standard Vision Fails)

For decades, standard terrestrial computer vision and satellite photogrammetry have relied on classical corner detectors and gradient descriptors: SIFT, ORB, SURF, and Normalized Cross Correlation (NCC).

1. Gradient Inversion

SIFT & ORB compute gradient vectors ∇I = [∂I/∂x, ∂I/∂y]. When shadows reverse 180°, gradient vectors point in exact opposite directions, yielding zero matching descriptors (correlation ρ = -0.96).

2. Lambertian Failure

Earth remote sensing assumes Lambertian diffuse scattering. Lunar regolith dust exhibits severe retro-reflective backscattering described by Lommel-Seeliger laws, breaking standard contrast algorithms.

3. Scale Pyramid Breakdown

SIFT octaves only tolerate up to 1.5×–2.0× scale ratios. OHRC vs TMC-2 is a 20× jump, causing feature keypoint detectors to fail completely.

How Samanvaya Solves Each Failure Mode

By switching from intensity gradients to frequency-domain phase congruency, the edge detection becomes mathematically invariant to light intensity. A physical crater rim always has a step change in elevation, so its Fourier phase components remain aligned regardless of whether the illuminated side is left or right.

Article 3 • Rigorous Mathematics

Mathematical Formulation & Core Algorithms

1. Lommel-Seeliger Regolith Scattering Law

Lunar regolith reflectance is non-Lambertian and governed by:

R_LS(i, e) = cos(i) / (cos(i) + cos(e))

where i is the solar incidence angle and e is the emission angle. Normalized reflectance strips out low-sun photometric gradients.

2. 2D Log-Gabor Phase Congruency & Kovesi Moments

Log-Gabor filters have a Gaussian transfer function on a logarithmic frequency scale with a strict Zero-DC response:

G(r, θ) = exp( -[ln(r/f₀)]² / 2[ln(σ_f)]² ) · exp( -[Δθ]² / 2σ_θ² )

The Maximum Moment (M_max) calculates the principal axis of step edge energy:

M_max = 0.5 * ( I_xx + I_yy + sqrt[ (I_xx - I_yy)² + 4(I_xy)² ] )

3. 2D Parabolic Taylor Sub-Pixel Optimization

For each integer match coordinate, an analytical bivariate 2D quadratic patch is fitted:

f(x, y) = a·x² + b·y² + c·x·y + d·x + e·y + f
Continuous Peak: δ* = -H⁻¹·g = [ (-2bd + ce)/(4ab - c²), (-2ae + cd)/(4ab - c²) ]ᵀ

Strict negative-definiteness (a < 0, b < 0, 4ab - c² > 0) guarantees true local maximum and sub-pixel accuracy below 0.40 pixels.

Article 7 • FAQ

Frequently Asked Questions

Can Samanvaya be used on Earth satellite imagery? ▼

Yes! While engineered for the Moon's airless regolith, the Phase Congruency and LoFTR pipeline is equally effective for Earth satellite imagery (e.g. mountainous topography under low winter sun vs high summer sun).

Why is Sub-Pixel RMSE < 0.40 px required by ISRO? ▼

Planetary cartographers merge stereo pairs to generate 3D Digital Elevation Models (DEMs). Any registration error greater than 0.5 pixels causes noticeable vertical elevation artifacts and cliff shears in 3D reconstruction.

How fast is the pipeline? Can it run on CPU? ▼

Yes! On standard multi-core CPUs, the pipeline completes in ~45–120 milliseconds for 256x256 to 512x512 patches. On GPU (CUDA), it executes in under 20 milliseconds, suitable for real-time spacecraft landing guidance.

Single-Command Deployment

One Command. Zero Headaches.

Just like world-class open source tools, Samanvaya sets up in seconds.

bash ~ samanvaya-terminal
# 1. Clone the repository
$ git clone https://github.com/ashishsinghbora/Samanvaya.git && cd Samanvaya
# 2. Single-command build & launch (Automatic Virtualenv + PyTorch + LoFTR)
$ make install && make run
# 3. Or launch headless CLI batch registration
$ samanvaya align -s source_ohrc.tif -r ref_lro.tif -o output/
