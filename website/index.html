Core Engineering Foundations

The 4 Computer Science Pillars

Built with rigorous mathematical algorithms, enterprise cybersecurity, distributed networking, and planetary astrophysics.

🧮

1. Data Structures & Algorithms (DSA) & OOP

  • • 2D FFT Log-Gabor Convolutions: O(N log N) vectorized frequency-domain tensor filtering.
  • • 8x8 Grid ANMS Partitioning: O(N) spatial hash-bucket sorting for crater rim anti-clumping.
  • • Bivariate Parabolic Taylor Solver: O(1) analytical Hessian inversion solving continuous peak δ* = -H⁻¹g.
  • • USAC-MAGSAC++ Consensus: Sequential probability hypothesis evaluation for robust homography.
  • • LRU Cache & Priority Queues: Custom O(1) Hash Map + Doubly Linked List caching and Min-Heaps for AI anomaly tracking.
  • • Polymorphic ML Architecture: Abstract Base Classes (ABC) and encapsulated inheritance for telemetry detectors.
🛡️

2. Cybersecurity & Systems Hardening

  • • PDS4 XML Entity Hardening: Neutralizes XXE attacks with disabled entity resolution.
  • • GeoTIFF Bomb & Buffer Mitigation: Strict raster dimension clamping preventing RAM exhaustion.
  • • Path Traversal Defense: Strict file URI sanitization disallowing ../ directory escapes.
  • • Non-Root Container Security: Docker microservices operate under unprivileged UID 1000.
🌐

3. Networking & Distributed Systems

  • • FastAPI Asynchronous Engine: Non-blocking event loops for high-throughput batch GeoTIFF alignment.
  • • Reactive WebSocket Streaming: Real-time progress broadcasting, tie-point coordinates, and latency metrics.
  • • GeoJSON Spatial Vector Streaming: Live chunked transmission of 2D displacement fields directly into GIS.
  • • Docker Service Mesh: Microservice isolation separating API router from Streamlit UI.
🛰️

4. Space Research & Photogrammetry

  • • Lommel-Seeliger Scattering: R_LS = cos(i)/(cos(i) + cos(e)) for non-Lambertian particulate regolith.
  • • Zero-DC Frequency Invariance: Rejects uniform illumination gradients from low sun angles.
  • • Lunar Coordinate Systems: Preserves Moon IAU 2000 cartographic projections (IAU2000:30100).
  • • USGS ISIS3 Bundle Adjustment: Exports sub-pixel GCPs formatted directly for Jigsaw tie-point optimization.
Zero-Friction Setup

One Command Installation

Ready for production, cloud servers, or local workstation development.

bash ~ samanvaya-quickstart
# 1. Clone the repository
$ git clone https://github.com/ashishsinghbora/Samanvaya.git && cd Samanvaya
# 2. Automated One-Command Installation & Portal Launch
$ make install && make run
# 3. Headless CLI batch alignment
$ samanvaya align -s source_ohrc.tif -r ref_lro.tif -o output/
