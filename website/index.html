Core Engineering Foundations

The 4 Computer Science Pillars

Built with rigorous mathematical algorithms, enterprise cybersecurity, distributed networking, and planetary astrophysics.

🧮

1. Data Structures & Algorithms (DSA)

Time-complexity optimized algorithms for gigapixel orbital image correspondence:

  • ▸ 2D FFT Log-Gabor Convolutions: O(N log N) vectorized frequency-domain filtering.
  • ▸ 8x8 Grid ANMS Partitioning: O(N) spatial hash-bucket sorting for crater rim anti-clumping.
  • ▸ Bivariate Parabolic Taylor Solver: O(1) analytical Hessian inversion: δ* = -H⁻¹g.
  • ▸ USAC-MAGSAC++ Consensus: Sequential randomized probability model with dynamic inlier thresholding.
🛡️

2. Cybersecurity & System Hardening

Enterprise defense-in-depth architecture guarding planetary ingestion pipelines:

  • ▸ PDS4 XML Entity Hardening: Neutralizes XXE (XML External Entity) attacks with disabled entity resolution.
  • ▸ GeoTIFF Bomb & Buffer Mitigation: Strict raster dimension clamping preventing RAM exhaustion and OOM DoS.
  • ▸ Path Traversal Defense: Strict file URI sanitization disallowing ../ directory escapes.
  • ▸ Non-Root Containerization: Docker microservices operate under restricted unprivileged UID 1000.
🌐

3. Networking & Distributed Systems

Asynchronous microservices architecture for mission control telemetry:

  • ▸ FastAPI Asynchronous Engine: Non-blocking event loops for high-throughput batch GeoTIFF alignment.
  • ▸ Reactive WebSockets Streaming: Real-time progress updates, tie-point coordinates, and latency metrics.
  • ▸ GeoJSON Vector Streaming: Real-time HTTP chunking of 2D displacement vector fields into QGIS / ArcGIS.
  • ▸ Docker Service Mesh: Microservice isolation separating the API router from the Streamlit UI.
🛰️

4. Space Research & Photogrammetry

Planetary physics tailored specifically for Chandrayaan-2 and lunar regolith:

  • ▸ Lommel-Seeliger Regolith Scattering: R(i, e) = cos(i) / (cos(i) + cos(e)) for non-Lambertian dust.
  • ▸ Zero-DC Log-Gabor Filtering: Guarantees zero response to uniform lighting offsets and albedo gradients.
  • ▸ Lunar Coordinate Systems: Preserves Moon IAU 2000 cartographic projections (IAU2000:30100).
  • ▸ USGS ISIS3 Bundle Adjustment: Exports sub-pixel GCPs formatted directly for Jigsaw tie-point optimization.

Zero-Friction Deployment

One-Command Installation

Engineered with a clean Makefile, portable installer script, and unified CLI command.

bash ~ samanvaya-quickstart
# 1. Clone the repository
$ git clone https://github.com/ashishsinghbora/Samanvaya.git
$ cd Samanvaya
# 2. Automated One-Command Installation (Virtualenv + PyTorch + LoFTR)
$ make install
# 3. Launch the Interactive Web Portal
$ make run # Or: samanvaya ui --port 8501
# 4. Or Run Headless CLI Alignment directly between GeoTIFFs
$ samanvaya align --source ohrc.tif --reference lro_nac.tif --output output/
